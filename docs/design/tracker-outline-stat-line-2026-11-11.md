# Tracker outline B and compact casting statistics

The user selected B from `tracker-outline-stat-line-2026-11-11.html`, with the
border following the current user's theme. Resource/slot cards retain their
layout and controls, using a faint accent tint over the surrounding panel and a
one-pixel border derived from the selected accent and existing theme line colour.
No colour is fixed to crimson; standard and custom accents react immediately.

Spell attack, Save DC and Casting appear together in a left-aligned, wrapping
line with thin separators. The large highlighted statistic strip and rail-only
casting paragraph are replaced by this same plain line in both variants.

At will, Known and prepare controls centre horizontally inside the existing
94px action gutter. On small screens, where actions already wrap below the
card, their row uses the card's full width to centre the contents. Card widths,
native disclosures, preparation and independent spell columns stay unchanged.
