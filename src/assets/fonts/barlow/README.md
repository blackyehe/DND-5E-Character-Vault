# Barlow sheet fonts

Barlow (400, 500, 600) and Barlow Condensed (500, 600), downloaded from the Google Fonts CSS API on 20 October 2026. The font files include the provider's Latin, Latin Extended and Vietnamese subsets and retain their original filenames.

The application serves these assets itself. `font-display: swap` keeps text visible while they load; switching to Classic typography uses system fonts.

Source: https://fonts.googleapis.com/css2?family=Barlow:wght@400;500;600&family=Barlow+Condensed:wght@500;600&display=swap

The SIL Open Font License and copyright notices are included in `barlow-OFL.txt` and `barlowcondensed-OFL.txt`, obtained from the corresponding directories in https://github.com/google/fonts/tree/main/ofl.
